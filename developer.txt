DEVELOPER FILE - SAFETY DETECTION SYSTEM

PROJECT IDEOLOGY

Problem Statement
Workers in construction sites must wear safety equipment like hard hats, safety vests, gloves, and safety glasses. Manual monitoring by supervisors is difficult and time consuming. This leads to safety violations going unnoticed.

Solution Approach
Develop an automated system that uses computer vision and artificial intelligence to continuously monitor workers and detect if they are wearing required safety equipment. The system alerts supervisors immediately when violations are detected.

Core Purpose
Improve workplace safety through automated continuous monitoring, reduce accidents by ensuring compliance, and create safer working environments.

WORKING PRINCIPLES

Basic Flow
Camera captures live video feed from webcam, each frame is extracted and preprocessed for AI model, processed frame is sent to trained neural network, model predicts which safety items are present or missing, system analyzes predictions to determine compliance status, results are displayed on screen and saved to storage.

Detection Process
Frame is resized to 224x224 pixels, image colors are converted from BGR to RGB format, pixel values are normalized between 0 and 1, preprocessed image is fed to AI model, model returns confidence scores for each safety item, scores above threshold indicate item is detected.

Compliance Checking
System checks if all four required items are detected with sufficient confidence, if all items present, status is marked as compliant, if any item missing, status is marked as violation, violation triggers alert sound and screenshot saving.

Data Management
Each detection result is saved with timestamp to JSON file, entry and exit times are tracked automatically based on compliance, statistics are calculated from stored data, data can be exported to CSV for analysis.

ALGORITHM USED

Image Classification Algorithm
Uses convolutional neural network CNN for image classification, CNN processes images in layers to identify patterns, lower layers detect basic features like edges and shapes, higher layers detect complex features like safety equipment, final layer outputs probability scores for each class.

Transfer Learning
Uses pre-trained EfficientNet model as base, pre-trained model already knows how to recognize objects in images, fine-tuned last few layers for PPE detection, this approach requires less training data and works better.

Classification Process
Input image is processed through multiple convolutional layers, each layer extracts more complex features, final fully connected layer maps features to classes, softmax function converts outputs to probabilities, highest probability class is the prediction.

HOW TO USE

Installation Steps
Install Python 3.8 or higher from python.org, open command prompt in project folder, run command: pip install -r requirements.txt, wait for all libraries to install

Running the System
Double click start.bat file, or run python run.py in command prompt, browser will open automatically, if not, go to http://localhost:5000

Login Process
Enter username and password on login page, default username: admin, default password: admin123, click Login button

Starting Detection
Click Start Detection button on main page, position yourself in front of camera, system will start analyzing frames, results appear on screen in real time

Viewing Information
Check Today's Entry Information for in and out times, view Statistics for compliance rates, see Daily Entries table for all detections today

Exporting Data
Click Export CSV button, file will download automatically, open in Excel or any spreadsheet software, analyze detection data

Stopping Detection
Click Stop Detection button, camera will stop processing, system continues to run in background

Logout
Click Logout button in header, returns to login page, session is cleared
